# Былина: Тьма Кощея

Пошаговая тактическая игра. Версия **0.17.0**: тактический слой (умения классов, состояния, призывы, туман войны, дозор, разрушаемая среда), сеть общего пользования: ретранслятор установления соединения (комнаты, перечень, обход NAT), повторное подключение при обрыве, запись и просмотр повторов партий.

Исходный код и сборка живут в этом каталоге. Нормативные документы — [`../doc/`](../doc/README.md).

```bash
cd app
pnpm install
pnpm test
pnpm dev
```

Запуск на Windows 10: `../doc/run-windows.md`.  
Подключение PixiJS: [`packages/render/README.md`](packages/render/README.md).
