# Былина: Тьма Кощея

Пошаговая тактическая игра. Версия **0.18.0**: тактический слой (умения классов, состояния, призывы, туман войны, дозор, разрушаемая среда), генералы: Баба Яга (полёт, контроль, пороговый уход и возвращение) и Соловей-Разбойник (скрытность, «Свист»); правила появления генералов в миссиях кампании.

Исходный код и сборка живут в этом каталоге. Нормативные документы — [`../doc/`](../doc/README.md).

```bash
cd app
pnpm install
pnpm test
pnpm dev
```

Запуск на Windows 10: `../doc/run-windows.md`.  
Подключение PixiJS: [`packages/render/README.md`](packages/render/README.md).
