# Былина: Тьма Кощея

Пошаговая тактическая игра. Версия **0.5.0** — одиночный режим «Быстрый матч».

Исходный код и сборка живут в этом каталоге. Нормативные документы — [`../doc/`](../doc/README.md).

```bash
cd app
pnpm install
pnpm test
pnpm dev
```

Запуск на Windows 10: `../doc/run-windows.md`.  
Подключение PixiJS: [`packages/render/README.md`](packages/render/README.md).
