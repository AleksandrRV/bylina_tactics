# Локализация
## «Былина: Тьма Кощея», версия 1.2

Предмет ведения: требования к языкам, устройство словарей и порядок расширения. Строки интерфейса в прочих документах приводятся на русском как языке описания; в программе они существуют только как ключи.

---

## 1. Требования

1. Выпуск обязан содержать два полных языка оболочки: русский (`ru`) и английский (`en`).
2. Число языков не ограничено. Добавление языка не требует изменения исходного кода модулей, схем данных и сетевых контрактов.
3. Исполнительные ядра, конфигурация JSON5 и пакеты обмена оперируют идентификаторами, а не человекочитаемыми строками.
4. Выбранный язык хранится в модуле настроек и восстанавливается при следующем запуске.

Язык описания комплекта документации — русский. Перевод самих нормативных документов не входит в объём игровой локализации.

---

## 2. Принцип реализации

Принят собственный модуль `app/packages/i18n` без внешней библиотеки перевода.

Основания выбора:

- ядра не зависят от объектной модели обозревателя и не должны тянуть связку с интерфейсом;
- новый язык подключается каталогом файлов и записью в манифесте, без правки TypeScript;
- объём кода сопоставим с обёрткой над готовой библиотекой, при этом нет скрытых форматов и привязки к конкретной среде;
- модуль испытывается в Node.js наравне с ядром.

Готовые каркасы (i18next и аналоги) не запрещены для замены модуля в будущем при сохранении внешнего договора: `t(ключ, параметры)`, список языков из манифеста, цепочка запасных каталогов.

---

## 3. Каталоги

```
app/packages/i18n/locales/
├─ manifest.json
├─ ru/
│  └─ ui.json
└─ en/
   └─ ui.json
```

`manifest.json` — единственный реестр языков:

```json
{
  "fallback": "ru",
  "languages": [
    { "code": "ru", "bcp47": "ru", "dir": "ltr", "nativeName": "Русский" },
    { "code": "en", "bcp47": "en", "dir": "ltr", "nativeName": "English" }
  ]
}
```

| Поле | Назначение |
|---|---|
| `code` | Идентификатор каталога и значение настройки |
| `bcp47` | Тег для `document.documentElement.lang` |
| `dir` | Направление письма (`ltr` или `rtl`) |
| `nativeName` | Название на этом языке; в переключателе не переводится |
| `fallback` | Полный каталог, на который опираются неполные языки |

Русский каталог обязан быть полным: он является запасным. Английский каталог выпуска 0.1.0 также полон для строк оболочки. Последующие языки могут быть неполными.

Имена файлов внутри языка свободны (`ui.json`, позднее `units.json` и т. д.). Загрузчик объединяет все JSON выбранного кода в один словарь.

---

## 4. Ключи и подстановка

Ключ — последовательность сегментов через точку: `menu.quickMatch`.

Словари хранят вложенные объекты. Значение — строка. Подстановка: фигурные имена `{version}`. Неизвестный параметр оставляется в тексте как `{version}`.

Правила:

- в исходном коде и в JSON5 запрещены литералы, видимые игроку;
- один смысл — один ключ; запрещено склеивать фразы из кусков разных языков;
- плюрализация на этапе 0.1.0 не применяется; при появлении зарезервированы суффиксы `key.one`, `key.few`, `key.many`, `key.other` по категориям CLDR, выбор категории — по тегу `bcp47`.

---

## 5. Разрешение строки

Порядок поиска значения ключа:

1. каталог выбранного `code`;
2. если код содержит регион (`en-GB`) и отдельного каталога нет — каталог языка (`en`);
3. каталог `fallback` (`ru`);
4. сам ключ (только как последний предохранитель; в режиме разработки фиксируется предупреждение).

Смена языка не перезагружает страницу: подписчики модуля перерисовывают оболочку. Атрибуты `lang` и `dir` корневого элемента документа обновляются одновременно.

---

## 6. Добавление языка

1. Создать каталог `app/packages/i18n/locales/<code>/` и скопировать в него JSON из `ru`.
2. Перевести значения, не меняя ключи.
3. Добавить элемент в массив `languages` файла `manifest.json`.
4. Запустить автоматические проверки пакета `i18n` (полнота относительно `ru` не обязательна, но дубли ключей и пустые значения запрещены).

Код модулей, сборка и схемы Zod не изменяются. Язык появляется в переключателе настроек после следующей сборки либо в режиме разработки — после перезапуска сборщика.

Удаление языка — обратная операция. Запись настройки с исчезнувшим кодом при запуске заменяется на `fallback`.

---

## 7. Границы ответственности

| Место | Что хранит |
|---|---|
| `app/packages/i18n` | Манифест, словари, функция `t`, список языков |
| `app/packages/settings` | Выбранный код языка |
| `app/packages/ui` | Ключи в компонентах, переключатель |
| `app/packages/content` | Идентификаторы сущностей (`bogatyr`), не названия |
| ядра | Только идентификаторы |

Имена существ, умений и миссий — ключи вида `unit.bogatyr.name`, `skill.whirlwind.name`. Они появляются вместе с соответствующим содержанием, не в 0.1.0.

---

## 8. Проверка

Автоматические испытания пакета обязаны подтверждать:

- наличие `ru` и `en` в манифесте;
- успешный перевод контрольного ключа на оба языка;
- переход на `fallback` при отсутствии ключа;
- подстановку параметра;
- отказ считать языком каталог, не указанный в манифесте.
