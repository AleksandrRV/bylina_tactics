# План исправлений проекта «Былина: Тьма Кощея»
## Версии 0.20.3 — 0.20.12

**Цель плана:** системно устранить все подтверждённые проблемы, выявленные в отчёте анализа версии 0.20.0 / 0.20.2.

**Принципы разбиения:**
- Каждая минорная версия фокусируется на **одной зоне ответственности**.
- Исправления вносятся последовательно, без смешивания зон.
- Каждая версия завершается обновлением документации и тестов.

---

**Критерии готовности:**
