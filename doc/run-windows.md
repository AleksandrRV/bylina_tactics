# Запуск и проверка на Windows 10
## «Былина: Тьма Кощея», версия 0.9.0

Предмет ведения: установка среды, запуск, сборка и перечень проверок выпуска 0.9.0 на персональной машине с системой Windows 10. Правила игры и устройство модулей в настоящий документ не входят.

---

## 1. Требования к машине

| Состав | Минимум |
|---|---|
| Система | Windows 10 версии 1903 или новее, разрядность 64 |
| Обозреватель | Google Chrome 120+ либо Microsoft Edge 120+ |
| Среда исполнения | Node.js 20 LTS (64-разрядный выпуск) |
| Диспетчер пакетов | pnpm 9 или 10 (через Corepack либо отдельная установка) |
| Место на диске | не менее 1 ГБ свободно в каталоге проекта и в профиле пользователя |
| Сеть | нужна один раз для загрузки Node.js и пакетов; дальнейшая работа в режиме разработки возможна без сети |

Права администратора требуются только для установки Node.js. Сборка проекта выполняется из обычной учётной записи.

---

## 2. Установка среды

### 2.1. Node.js

1. Открыть [https://nodejs.org/](https://nodejs.org/) и скачать выпуск **20 LTS** для Windows x64 (файл `.msi`).
2. Запустить установщик. Оставить предложенный каталог. Включить пункт добавления в `PATH`.
3. Закрыть все окна командной строки, открыть **новое** окно PowerShell и выполнить:

```powershell
node -v
npm -v
```

При отказе «running scripts is disabled» выполнить **один раз** в PowerShell:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Подтвердить `Y`. Это разрешает локальные сценарии текущего пользователя и не меняет политику машины.

Ожидается строка вида `v20.x.x` и номер npm. Если команда не найдена — выйти из учётной записи и войти снова либо проверить `PATH`.

### 2.2. pnpm

В том же окне PowerShell:

```powershell
corepack enable
corepack prepare pnpm@9.15.0 --activate
pnpm -v
```

Если `corepack` недоступен:

```powershell
npm install -g pnpm
pnpm -v
```

## 3. Получение проекта и установка зависимостей

Открыть PowerShell. Перейти в каталог `app` (рядом с ним на уровень выше лежит `doc`):

```powershell
cd C:\path\to\bylina\app
pnpm install
```

Первая установка занимает несколько минут. Успех — отсутствие ошибки в последней строке и появление каталогов `node_modules`.

Не использовать одновременно `npm install` в этом репозитории: появится второй файл блокировок.

---

## 4. Команды

Выполнять из каталога `app`.

| Команда | Назначение |
|---|---|
| `pnpm dev` | Сервер разработки с обновлением при сохранении файлов |
| `pnpm test` | Автоматические проверки пакетов |
| `pnpm typecheck` | Проверка типов TypeScript |
| `pnpm build` | Производственная сборка прогрессивного веб-приложения |
| `pnpm preview` | Просмотр производственной сборки |

Адрес режима разработки по умолчанию: `http://127.0.0.1:5173/`.  
Адрес просмотра сборки: `http://127.0.0.1:4173/`.

Остановка сервера: в окне PowerShell нажать `Ctrl+C`.

Если порт занят, сборщик выберет следующий свободный и напечатает фактический адрес. Открывать нужно его.

## 5. Проверка выпуска 0.9.0

Последовательность обязательна после `pnpm install`.

### 5.1. Автоматические проверки

```powershell
pnpm test
pnpm typecheck
```

Ожидается успешное завершение без упавших наборов. Падают — к ручной проверке оболочки не переходить.

```powershell
pnpm dev
```

### 5.3. Производственная сборка

Остановить `pnpm dev`. Выполнить:

```powershell
pnpm build
pnpm preview
```

Открыть напечатанный адрес и повторить таблицу раздела 5.2. Поведение должно совпадать.

## 6. Установка как приложения Windows

1. Собрать и открыть `pnpm preview` либо развернуть каталог `app/apps/game-pwa/dist` на любом статическом сервере по `https`.
2. В Chrome или Edge открыть приложение.
3. В строке адреса нажать значок установки либо выбрать в меню обозревателя «Установить приложение» / «Install app».
4. Запуск — из меню «Пуск» по имени «Былина».

На `http://127.0.0.1` установка может быть ограничена политикой обозревателя. Для проверки установки достаточно режима разработки на `localhost` в Chrome: значок установки появляется в адресной строке.

## 7. Частые отказы

| Наблюдение | Действие |
|---|---|
| `pnpm` не является командой | Повторить раздел 2.2 в **новом** окне PowerShell |
| `node` не является командой | Переустановить Node.js с отметкой `PATH`, открыть новое окно |
| Ошибка политики сценариев | Раздел 2.1, сразу после `node -v` |
| `EPERM` / файл занят при `pnpm install` | Закрыть обозреватель и среду разработки, удалить `node_modules`, повторить установку |
| Страница пустая | Открыть средства разработчика (`F12`), вкладка Console; убедиться, что открыт адрес из вывода `pnpm dev` |
| Порт 5173 занят | Использовать адрес, который напечатал сборщик |
| `Failed to resolve import "pixi.js"` | Остановить сервер, из `app` выполнить `pnpm install`, затем `pnpm dev`. Порядок — `app/packages/render/README.md` |
| Поле чёрное, панель есть | Включить аппаратное ускорение обозревателя (WebGL); обновить вкладку |
| Язык сбросился | Проверить, что обозреватель не работает в режиме инкогнито и не блокирует `localStorage` |

## 8. Что не проверяется в 0.9.0

Кампания, постоянная дружина, генералы и сеть в этом выпуске отсутствуют. Волхв и его умения полностью представлены в конфигурации и ядре, но не занимают четвёртый слот «Быстрого матча». Их применение проверяется автоматическими сценариями до открытия кампании.
