# Комплект проектной документации
## «Былина: Тьма Кощея» (Bylina Tactics), версия 1.3

Настоящий комплект является единственным нормативным описанием проекта. При расхождении формулировок применяется документ, за которым закреплена соответствующая предметная область (таблица ниже). Числовые значения баланса, не указанные здесь явно, хранятся исключительно в файлах конфигурации формата JSON5 и проверяются схемами Zod.

### Назначение документов

| Документ | Предмет ведения | Не содержит |
|---|---|---|
| [base-design.md](base-design.md) | Замысел, цикл кампании, состав дружины и противников, режимы, изобразительные принципы | Формулы, поля сетевых пакетов, состав программных модулей, вёрстку экранов |
| [progression.md](progression.md) | Постоянная прогрессия: опыт и уровни бойцов, специализации, развитие Летучего Корабля, ярусы экипировки, захват и исследование противников, кривая сложности | Формулы боя, сетевые контракты, вёрстку экранов |

### Инварианты, обязательные для всех документов

1. Живая сущность занимает ровно одну клетку. Сущностей, занимающих несколько клеток, не существует.
2. Исполнение правил тактического боя производится только ведущим участником (host).
3. Интерфейс и средство отображения не изменяют игровое состояние напрямую.
