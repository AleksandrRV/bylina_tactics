# Комплект проектной документации
## «Былина: Тьма Кощея» (Bylina Tactics), версия 1.1

Настоящий комплект является единственным нормативным описанием проекта. При расхождении формулировок применяется документ, за которым закреплена соответствующая предметная область (таблица ниже). Числовые значения баланса, не указанные здесь явно, хранятся исключительно в файлах конфигурации формата JSON5 и проверяются схемами Zod.

### Назначение документов

| Документ | Предмет ведения | Не содержит |
|---|---|---|
| [base-design.md](base-design.md) | Замысел, цикл кампании, состав дружины и противников, режимы, изобразительные принципы | Формулы, поля сетевых пакетов, состав программных модулей, вёрстку экранов |
| [math.md](math.md) | Алгоритмы сетки, зрения, боя, перемещения и состояний | Классы персонажей как художественные образы, сетевые контракты, элементы интерфейса |
| [content-schema.md](content-schema.md) | Структура файлов конфигурации и смысл полей | Алгоритмы расчёта, описание модулей |
| [ecs-schema.md](ecs-schema.md) | Компоненты и архетипы исполнительной среды bitECS | Формулы боя, макеты интерфейса |
| [network-protocol.md](network-protocol.md) | Форматы команд, событий, снимков и запросов предпросмотра | Правила вычисления видимости и урона |
| [tech-core.md](tech-core.md) | Границы программных модулей и поток данных | Игровые формулы, визуальный стиль |
| [tech-stack.md](tech-stack.md) | Состав технологий, структура репозитория, этапы реализации | Игровые правила |
| [ui-design.md](ui-design.md) | Экраны, управление, правила отображения | Игровая логика и формулы |
| [roadmap.md](roadmap.md) | Этапы, выпуски, критерии проверки | Игровые формулы, макеты, контракты |
| [improvements.md](improvements.md) | Пожелания игроков и план доработок по итогам обзора версии 0.18.0 | Игровые правила, формулы, контракты |
| [i18n.md](i18n.md) | Языки, словари, порядок расширения | Макеты экранов, игровые формулы |
| [debug-mode.md](debug-mode.md) | Средства отладки и проверки (оверлей стоимости, автопобеда, полигон) | Игровые правила, баланс |
| [run-windows.md](run-windows.md) | Запуск и проверка на Windows 10 | Архитектура модулей |

### Порядок ознакомления

1. Замысел — `base-design.md`
2. Правила расчёта — `math.md`
3. Данные и исполнительная среда — `content-schema.md`, `ecs-schema.md`
4. Взаимодействие программ — `network-protocol.md`, `tech-core.md`, `tech-stack.md`
5. Представление — `ui-design.md`
6. Порядок работ — `roadmap.md`; пожелания игроков и план доработок — `improvements.md`
7. Языки — `i18n.md`
8. Запуск на Windows 10 — `run-windows.md`

Журнал устранения противоречий предыдущей редакции: [changelog-1.1.md](changelog-1.1.md).

### Инварианты, обязательные для всех документов

1. Живая сущность занимает ровно одну клетку. Сущностей, занимающих несколько клеток, не существует.
2. Исполнение правил тактического боя производится только ведущим участником (host).
3. Интерфейс и средство отображения не изменяют игровое состояние напрямую.
